# Runforge · Runs

Страница для просмотра запусков AI-агентов. Тестовое задание на React, TypeScript, Vite и SCSS Modules. Данные загружаются из локального mock-сервиса.

## Запуск

Нужен Node.js 22.12+ или 24 LTS.

```sh
npm ci
npm run dev
```

Откройте [http://127.0.0.1:5173](http://127.0.0.1:5173) или адрес из терминала, если порт занят.

## Возможности

- Список запусков с названиями, репозиториями, ветками, статусами, датами и длительностью.
- Поиск по названию и репозиторию, фильтр по статусу и сортировка по дате или длительности. Поиск и статус сохраняются в URL.
- Детали запуска с логами и результатом. Откройте их кликом по строке или клавишей Enter. Закройте крестиком, клавишей Escape или кликом по затемнению.
- Состояния загрузки, ошибки и пустой выдачи. На узком экране строки отображаются как карточки.

## Проверки

| Команда | Что делает |
| --- | --- |
| `npm run check` | Проверяет форматирование, ESLint и типы |
| `npm run lint` | Запускает ESLint |
| `npm run format` | Форматирует файлы через Prettier |
| `npm test` | Запускает 8 тестов интерфейса |
| `npm run build` | Собирает приложение в `dist/` |

Тесты покрывают фильтры, поиск, URL, сортировку, детали запуска и повтор после ошибки.

## Структура

```text
src/
  components/       список, фильтры и детали запусков
  hooks/            загрузка, фильтрация и сортировка
  data/runs.ts      тестовые данные
  services/runs.ts  асинхронный mock-сервис
  App.test.tsx      тесты интерфейса
```
