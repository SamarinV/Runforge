# Использование ИИ в Runforge

**Инструмент** — OpenAI Codex (desktop), модель семейства GPT-6.

Codex использовался для разбора ТЗ, реализации страницы Runs, подготовки тестов и редактирования документации.

## Запросы и контекст

Формулировки сокращены для отчёта.

| Запрос | Переданный контекст | Результат |
| --- | --- | --- |
| Оценить объём задания и составить порядок работы | PDF с требованиями, моделью `Run` и критериями оценки | План реализации списка, фильтрации, деталей и состояний загрузки |
| Разбить `App.tsx` на компоненты и хранить стили рядом с ними | Исходный код страницы и правила проекта по TypeScript и SCSS Modules | Компоненты списка, фильтров и деталей получили собственные SCSS-модули |
| Переработать тесты, чтобы они проверяли сценарии пользователя | Текущие тесты, данные запусков и требования к поиску, фильтрации и деталям | Проверки конкретных строк, восстановления фильтров из URL, сортировки и закрытия деталей |

## Корректировка решения

При проверке интерфейса обнаружилось, что клик по затемнению не закрывал модальное окно. Codex предложил проверять координаты клика относительно границ `<dialog>`. После просмотра кода я попросил упростить обработку. В итоговой версии затемнение стало отдельным элементом: клик по нему вызывает закрытие. Тест проверяет оба случая — клик по затемнению закрывает окно, клик по содержимому оставляет его открытым.

## Проверка

Последний прогон `npm run check` подтвердил форматирование, ESLint и типы. `npm test` прошёл все 8 сценариев, включая фильтрацию, сортировку, подробности запуска и повтор запроса после ошибки.
